### 🚀 Live Demo

**[Credit Risk Project](https://credit-risk-project-mpl0.onrender.com/)**

### 🛠️ Technologies

* Python
* FastAPI
* XGBoost
* Scikit-learn
* Pandas
* HTML, CSS & JavaScript

### 📌 Features

* Credit risk prediction
* Machine learning model
* REST API with FastAPI
* Interactive web interface
